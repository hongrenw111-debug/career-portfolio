## 证据等级

| 等级 | 含义 | 页面可以怎么写 |
|---|---|---|
| A | 本轮通过当前代码或只读验证器重新核对 | “已验证”“当前快照” |
| B | 当前源码结构存在，但本轮没有执行完整测试 | “已实现”“建立了测试覆盖” |
| C | 跨 Agent 共享记忆中记录的本地成果 | “本地已配置/已验证”，同时说明待公开整理 |
| D | 计划中的公开化改造 | 只能放在“下一步”，不能写成当前能力 |

## cs2-arb（CS2 跨平台套利决策辅助工具）

### 可公开事实

- **A**：2026-10-22 实测 `npm test`：25 个测试文件、258 个用例全部通过，3.65 秒，全程离线。
- **A**：`docs/adr/` 三份决策记录——行情走聚合 API 而非自爬私有接口、只做决策辅助不做自动化、费用与冷却期必须可配置。
- **A**：放弃自爬悠悠有品私有接口的理由是实测结论：该接口需约 10 天过期的 Bearer token、AES 设备码，且有 TLS 指纹检测、数据中心 IP 风控（错误码 84104）与限频。
- **A**：Steam 侧自限 ≤15 req/min，并明确拒绝代理轮换——该做法有账号锁定的实测代价。
- **A**：手续费、提现成本、Steam 余额折价（约 7 折）与 7 天交易冷却期都进入收益模型，而非只算价差。

### 当前漂移

- 项目为**决策辅助**，不做自动交易；Steam 订阅协议禁止 bot 自动化，边界已写入 ADR-0002。
- `fixtures/` 下的行情快照是录制的历史数据，离线测试与实时扫描是两条路径，公开演示以快照为主。
