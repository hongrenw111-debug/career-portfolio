## 证据等级

| 等级 | 含义 | 页面可以怎么写 |
|---|---|---|
| A | 本轮通过当前代码或只读验证器重新核对 | “已验证”“当前快照” |
| B | 当前源码结构存在，但本轮没有执行完整测试 | “已实现”“建立了测试覆盖” |
| C | 跨 Agent 共享记忆中记录的本地成果 | “本地已配置/已验证”，同时说明待公开整理 |
| D | 计划中的公开化改造 | 只能放在“下一步”，不能写成当前能力 |
