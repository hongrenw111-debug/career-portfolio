# Case Study 03 — AIGC 图像量产与一致性工作流

## 结论

当前完成的是**日用的个人批量生图工作流**：以强制垫图加特征提示词约束控制角色一致性与画风，配合浏览器自动化与 Canvas 无损提取、固定后处理链，单张资产制作周期由小时级压缩至一分钟以内，支持百张级批量交付。

## Constraint

- 大模型批量生图时角色面部形变、画风漂移，逐张手调不可扩展。
- 交付级资产要求透明通道、白底处理与目标规格对齐，而生成模型并不保证这些。
- 浏览器端生成结果受反爬与画质压缩影响，直接截图会损失分辨率。

## Decision

- **一致性用约束解决**：参考图垫图锁定面部、服饰与体型，结构化提示词模板约束画风与细节，而不是依赖模型自觉。
- **无损提取**：通过 Playwright 控制浏览器，在离线 canvas 节点执行 drawImage 与 toDataURL，取回原始分辨率 Base64，规避截图压缩。
- **固定后处理链**：白底智能抠图、边缘羽化、规格对齐固化为标准流程，不逐张手工修。

## Mechanism

```text
需求 / 原画参考
→ 垫图 + 特征提示词模板
→ 图像模型批量生成
→ 离线 Canvas 无损提取
→ 白底抠图 → 边缘羽化 → 规格对齐
→ 批量交付（立绘 / 图标 / 连续动作姿态）
```

## Evidence

- 同一角色在不同装备与动作下保持面部与画风一致。
- 单图制作周期由小时级压缩至 1 分钟以内（含后处理）。
- 产出资产直接用于实际交付场景，覆盖立绘、图标与连续动作姿态。
- 工作流以参数化脚本驱动，输入与提示词可替换复用。
