# Resume Bullets

以下文案已经按当前证据边界收敛。补充公开仓库链接和新鲜测试结果后，可直接用于中文简历。

## 个人摘要

面向 AI 运营与 AI 应用岗位：既能做内容生产、自动化触达与数据复盘，也能亲手把 AI 工作流做成带护栏、可验证的工程系统。

## Job Apply Agent

- 独立开发求职 Agent：JD 解构为需求清单、逐条证据映射、按岗定制简历与话术；定制内容 100% 取材主简历，对齐不足标记 cannot-align 直接放弃投递。
- 设计事实单元规约校验（时间线 / 数字必须回指主简历 + 关键词堆砌检测），配合节奏护栏（每轮上限、连续失败熔断、±20% 间隔抖动、验证码秒停）。
- 107 项单元与集成测试全绿（2026-09-14 `node --test` 实测），投递默认 dry-run 起步。

## AIGC 图像量产管线

- 设计"强制垫图 + 特征提示词约束"方案，解决批量生图的角色形变与画风漂移，同一角色跨装备与动作保持一致。
- 结合 Playwright 驱动生成、离线 Canvas 无损提取与固定后处理链（抠图 / 羽化 / 规格对齐），单图周期由 1 小时压缩至 1 分钟，支持百张级交付。

## 小红书内容自动化引擎

- 打通热点嗅探、图文生成到创作者中心发布的全自动链路，无头静默运行，键盘级输入节奏。
- 发布 / 存草稿双模式护栏：发布必须显式指定，默认存草稿防误发（经 2026-09-14 回归修复确认）。

## Provider Reliability / AgentGate

- 设计并运行双通道 Gemini Provider Guard，隔离 Provider 后端与 8+8 无重叠节点池，按网络、地区、上游 5xx、后端、配额与鉴权根因选择恢复动作。
- 实现节点健康探测、冷却状态、候选并行探测、连接取消传播与安全重放边界；响应头或首个响应字节发出后禁止自动重放。
- 构建事务化安装与只读验证流程，检查运行任务、端口所有权、模型目录、节点池、恢复所有权和日志脱敏。

> 等通用 Provider adapter、OpenTelemetry 和故障注入公开版完成后，再将标题升级为“多 Provider AI Gateway”。

## Local AI Media Pipeline

- 面向 RTX 3060 6GB VRAM / 16GB RAM 的 Windows 设备，固化 MiniMax H3 + LightX2V 低显存图生视频工作流和可重复采样配置。
- 将 ComfyUI 工作流抽成后端 API Runner，并连接自动媒体组装与剪映草稿导出，减少 GUI 手工操作和环境漂移。

## Agent Skill Router

- 建立自然语言到代码图谱、诊断、实现、设计、浏览器和多媒体工具的八域意图矩阵，降低用户对工具命令的记忆成本。
- 通过单一调度入口按需检索 230+ 专业角色，并使用共享记忆协调 Codex、ZCode 和 WorkBuddy 的跨会话分工。

## CS2 Simulator

- 设计 TypeScript monorepo 的本地只读套利决策与对账工作台，拆分 React/Vite Web、Fastify API、Chrome MV3 采集器及独立 contracts/domain/persistence 包。
- 构建逐档订单簿与四段套利评估模型，使用最小货币单位处理金额，综合深度、滑点、费用版本、行情时效和资金占用生成可解释拒绝码。
- 使用 SQLite 追加式事件账本实现交易事实幂等、payload 冲突检测、单调同步游标、状态重放和副本恢复演练。
- 为本地采集链路实现 GET 来源白名单、一次性交接、HttpOnly 同源会话、CSRF 校验和失败关闭策略。

## RyzaChat:AI

- 开发 Windows 本地 AI 角色互动游戏，整合 OpenAI 兼容模型接口、TTS、Spine 4.2 WebGL、多会话存档与角色卡配置。
- 构建 34 个场景变体的按需纹理加载，以及 74 条环境音的昼夜切换、交叉淡化和语音闪避，降低本地显存与音频竞争压力。
- 将 MediaPipe 面捕拆为独立 Web 客户端，把头部姿态、眨眼、口型与表情映射到角色骨骼，并提供 OBS 浏览器源模式。

> 公开仓库前先修复安全审计缺陷，并将不可再分发的原始素材替换为占位资源。

## 面试主线

不要按“我用了哪些框架”展开，而按以下顺序：

1. 系统受到什么约束；
2. 最危险的失败模式是什么；
3. 为什么选择现在的边界而不是更复杂方案；
4. 哪些请求可以安全重放，哪些绝对不能；
5. 如何用验证器、测试或恢复演练证明结果；
6. 当前还有哪些证据缺口。
