## 个人摘要

面向 AI 运营与 AI 应用岗位：既能做内容生产、自动化触达与数据复盘，也能亲手把 AI 工作流做成带护栏、可验证的工程系统。

## FlowForge（开源 AI 导演调度工作台）

- 主导开发并公开开源 Agent 原生 AI 导演调度工作台（FlowForge），复用本地 Chrome 会话安全上下文，通过 CDP 协议零 API Key 驱动 Google Flow 电影级生成管线。
- 首创尾帧接力模式（抽取上一镜第 8 秒末尾帧注入下一镜首帧），实测 MAD（平均绝对差）= 2.00 像素级无缝运镜，配合原画首帧锚定彻底解决长视频角色变脸难题。
- 研发伪视频损坏熔断门禁（moov atom 完整性探测与 <100KB 自动重试），配置 Ubuntu + Windows 双系统 GitHub Actions CI，全量 209 个单元测试回归通过（最后一次成功运行 2026-09-01）。

## 小红书内容自动化引擎（含 AIGC 合规检测）

- 搭建内容生产工作台（热点嗅探 → 文案两道工序 → 3:4 卡片渲染 → 发布），并**在发布链路上加一层可复现的 AIGC 合规闸门**：17 条规则覆盖《广告法》第九条、小红书《AI 内容治理规则》四类禁止行为、《AI 生成合成内容标识办法》第十条。
- **用平台真实审核拒绝数据反向校准规则**：从创作者中心「修改建议」取证拒绝原文，发现 2 篇内容在旧规则下完全通过却被平台实际拒绝（站外平台信息 / 诱导互动），据此补出两类规则，使同类问题可在发布前拦下（命中文本与平台原文一致）。
- 检测器设计为纯函数（零 IO / 零网络 / 零 LLM），分级闸门：`block` 发布时硬拦截、`warn` 只提示；防误杀经 44 篇真实语料回归（初版误杀 16 篇 → 加放行窗口后清零），真实命中固化为回归测试。
- 存量违规内容用确定性修复器处理，**未通过 13 → 0**，改动仅 0.15%，修复后复检通过才允许发布；闸门经端到端验证（在打开浏览器之前即拦下违规笔记）。
- 打通创作者中心平铺 DOM 数据回收 → `metrics.jsonl` → 周报（LLM 故障可降级）；`tsc` 零错误、**175+ 个测试全绿**。

> **面试可讲的关键判断**：我最初做的是"全自动发布"，读到平台规则明令禁止「利用 AI 工具自动运营账号」后改成"备稿全自动 + 发布人工确认"。理由是违规代价真实——该账号 6 篇已发布内容中 2 篇被判「未通过」。这个取舍比"我能做全自动"更能体现风控意识。

## Job Apply Agent

- 独立开发求职 Agent：JD 解构为需求清单、逐条证据映射、按岗定制简历与话术；定制内容 100% 取材主简历，对齐不足标记 cannot-align 直接放弃投递。
- 设计事实单元规约校验（时间线 / 数字必须回指主简历 + 关键词堆砌检测），配合节奏护栏（每轮上限、连续失败熔断、±20% 间隔抖动、验证码秒停）。
- 107 项单元与集成测试全绿（2026-09-14 `node --test` 实测），投递默认 dry-run 起步。

## ego-win（ego lite 官方 harness 的 Windows 宿主）

- 用 CDP 实现 ego lite（macOS 应用，上游 SDK 开源 MIT）在 Windows 上缺失的 `globalThis.ego` 原生绑定层；上游 SDK 逐字节 vendored 于固定 commit，83 万字节代码一行未改。
- 判断依据是接缝位置：原版整套 Page 模型、refs、定位符、等待、弹窗与下载都由上游提供，Windows 缺的只是浏览器注入的那 15 个原生绑定，因此只补这一层而不是重写 API。
- 实测 `npm test` 63/63 通过；上游真实浏览器套件 68/69 个 case 通过（唯一失败为剪贴板粘贴，已记为已知短板）。
- 自建组合测试套件覆盖功能之间的接缝，它发现了上游套件看不到的 `snapshotFast` ref 注册缺陷，现为绑定层改动后的固定闸门。

## AIGC 图像量产管线

- 设计"强制垫图 + 特征提示词约束"方案，解决批量生图的角色形变与画风漂移，同一角色跨装备与动作保持一致。
- 结合 Playwright 驱动生成、离线 Canvas 无损提取与固定后处理链（抠图 / 羽化 / 规格对齐），单图周期由 1 小时压缩至 1 分钟，支持百张级交付。

## Provider Reliability / AgentGate

- 设计并运行双通道 Gemini Provider Guard，隔离 Provider 后端与 8+8 无重叠节点池，按网络、地区、上游 5xx、后端、配额与鉴权根因选择恢复动作。
- 实现节点健康探测、冷却状态、候选并行探测、连接取消传播与安全重放边界；响应头或首个响应字节发出后禁止自动重放。
- 构建事务化安装与只读验证流程，检查运行任务、端口所有权、模型目录、节点池、恢复所有权和日志脱敏。

## cs2-arb（CS2 跨平台套利决策辅助）

- 开发悠悠有品 ↔ Steam 的 CS2 饰品套利决策辅助 CLI，把手续费结构、提现成本、余额折价与 7 天交易冷却期建成可配置模型，而非只算价差。
- 先做数据源可行性探测再决定方案：实测私有接口需约 10 天过期 token、AES 设备码、TLS 指纹检测与数据中心 IP 风控，判定不适合做行情层，改走聚合 API；Steam 侧自限 ≤15 req/min 并拒绝代理轮换（该做法有账号锁定代价）。
- 25 个测试文件、258 个用例全绿（2026-10-22 实测，全离线 3.65 秒）；三份 ADR 记录行情来源、不做自动交易、费用必须可配置三项决策。

## RyzaChat:AI

- 开发 Windows 本地 AI 角色互动游戏，整合 OpenAI 兼容模型接口、TTS、Spine 4.2 WebGL、多会话存档与角色卡配置。
- 构建 34 个场景变体的按需纹理加载，以及 74 条环境音的昼夜切换、交叉淡化和语音闪避，降低本地显存与音频竞争压力。
- 将 MediaPipe 面捕拆为独立 Web 客户端，把头部姿态、眨眼、口型与表情映射到角色 298 根骨骼，并提供 OBS 浏览器源模式。
